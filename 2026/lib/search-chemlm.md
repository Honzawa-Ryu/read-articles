## エグゼクティブ・サマリー (Executive Summary)

本レポートは、化学構造表現から毒性（Toxicity）および薬効・生理活性（Efficacy / Bioactivity / ADMET）を予測するAI技術、特に **化学言語モデル (Chemical Language Models: ChemLM / Molecular LMs)** に関する2026年時点における最先端の研究動向・アーキテクチャ・定量ベンチマーク評価および課題解決アプローチを包括的に網羅した体系的調査報告書である。

従来のケモインフォマティクスでは、Morganフィンガープリント (ECFP) などの固定的記述子や、グラフニューラルネットワーク (GNN) による分子グラフ表現が主導的役割を果たしてきた。しかし、2020年前後からの自然言語処理 (NLP) の大規模 Transformer アーキテクチャの急速な進展に伴い、分子構造を1次元文字列 (SMILES, SELFIES, InChI等) として捉え、大規模な無ラベル分子コーパスで事前学習を行う**化学言語モデル**が台頭した。

本サーベイの分析により明らかとなった要点は以下の通りである：

1. **表現学習の深化と3D情報の暗黙的獲得:**
   初期の **ChemBERTa** (10M SMILES) から、11億分子を学習した **MoLFormer** において、1次元 SMILES から学習された線形アテンション重みが分子内原子間距離の幾何学的相関（3D構造情報）を自然に獲得していることが実証された。さらに **ChemBERTa-2** が明らかにしたように、マスク化言語モデル (MLM) よりも複数記述子を同時に回帰する多重タスク回帰 (MTR) 事前学習が下流タスク精度を大幅に引き上げる。
2. **定量性能とGNNとの統合 (MoleculeNet ベンチマーク):**
   MoLFormer-XL は MoleculeNet の分類タスク (BBBP: 93.7%, ClinTox: 94.8%, BACE: 88.2%, Tox21: 84.7%) において、最強のグラフモデルである **D-MPNN (Chemprop)** を匹敵あるいは凌駕する性能に達した。しかし、新規骨格に対する汎化能力（Scaffold Split 評価）においては、1D言語モデル単独よりも **マルチモーダル統合 (1D文字列 + 2Dグラフ + 3D構造)** や **ハイブリッド注意機構** が有効である。
3. **化学基盤モデルと対話型創薬プラットフォームの展開:**
   **MolT5**, **Galactica**, **Mol-Instructions**, **ChemMamba**, **ChemDFM**, **LlaSMol**, **ChemLLM** などにより、分子式予測にとどまらない「自然言語による分子説明文生成」「化学推論・薬理作用機序の対話型説明」を行うマルチ・ケミカル LLM フレームワークが確立された。
4. **化学的構文論と信頼性・安全性対策:**
   生成および予測時の構文妥当性 (Syntax Validity) 問題は、100%文法性を保証する **SELFIES** 表記や構文制約付きトークナイズにより解決されつつある。また、活性クリフ (Activity Cliff) やデータ漏洩に対する解釈可能性 (Attention Analysis) 評価により、薬理団 (Pharmacophore) や構造毒性相関 (SAR) を視覚化・説明可能な創薬パイプラインへと発展している。

## 1. 化学構造表現の基礎と化学言語モデルの歴史的変遷

### 1.1 分子構造表現法の体系的比較：1D文字列 vs 2D/3Dグラフ
機械学習モデルに化学分子を入力するためには、化学構造を離散記号列あるいはデータ構造に変換する必要がある。各表現法は、文法厳密性・一意性・幾何情報保持率においてトレードオフが存在する。

```
                     +---------------------------------+
                     |  化学分子 (Molecular Structure)   |
                     +---------------------------------+
                       /                |               \
                      /                 |                \
         +-------------------+  +-----------------+  +----------------------+
         | 1D 文字列表現     |  | 2D グラフ表現   |  | 3D 空間座標表現      |
         | (SMILES, SELFIES) |  | (Nodes & Edges) |  | (Conformers, XYZ)    |
         +-------------------+  +-----------------+  +----------------------+
                   |                     |                      |
             化学言語モデル             GNN / D-MPNN        等変GNN / 3D拡散モデル
          (ChemBERTa, MoLFormer)        (Chemprop, GIN)    (EGNN, SchNet, BioNeMo)
```

| 表現法 | 表現構造・規格 | トークナイズ適性と文法厳密性 | 長所 (メリット) | 短所・課題 (デメリット) |
|:---|:---|:---|:---|:---|
| **SMILES** | 深さ優先探索 (DFS) による ASCII 文字列 | 正規表現 / BPE。構文エラー（括弧の不一致や開環不整合等）が発生し得る | 人間に可読で広く流通。文字列長がコンパクトで一般的なTransformerに直接適用可能。 | 同一分子に対して複数の有効表記が存在 (非一意性)。部分構造変異時に構文破壊が発生しやすい。 |
| **SELFIES** | チョムスキー階層に基づく状態遷移型文字列 | 定義済みトークン辞書。あらゆるトークン列が **100% 構文妥当な分子** となる | 文法エラーがゼロ。生成モデルやデコーダタスクにおいて不正分子生成を完全に抑制。 | 文字列長がSMILESより約30〜50%長く、長いコンテキストを要する。空間立体情報の表現に制限。 |
| **InChI / InChIKey** | IUPAC階層構造化文字列 (式, 原子結合, 水素, 立体化学等) | 階層分割。厳格な正準表現だが局所構造の編集・学習が困難 | **完全に正規化・一意化** された識別子。データベース照合や構造重複排除に最適。 | 人間およびLMにとって構文規則が過度に硬直・複雑で、部分構造学習の汎化性が低い。 |
| **分子グラフ (2D Graph)** | ノード(原子)とエッジ(結合)の隣接行列および属性行列 | ノード・結合エンべディング。グラフ同型性検定に基づく学習 | 化学的トポロジーおよび局所結合性を直接的に反映。構造変異の影響が局所化される。 | 遠隔原子間相互作用（長距離依存）の把握に層の深いメッセージパッシングが必要（過剰平滑化問題）。 |
| **3D 立体配座 (Conformer)** | 3次元ユークリッド空間上の原子座標 $(x,y,z)$ | 等変・不変表現 (EGNN 等)。回転・並進に対する幾何等変性 | 立体異性体・薬理ポケットとの相互作用・静電ポテンシャルを直接表現可能。 | 同一分子に対して無限の配座が存在。座標計算コストが高く大規模事前学習にデータ制約。 |

### 1.1.1 SMILES 文法規則の完全解剖と正準化アルゴリズム (Canonical SMILES & Isomeric SMILES)

SMILES (Simplified Molecular Input Line Entry System) は Weininger (1988) により提唱された、分子の2Dグラフ構造を深さ優先探索 (DFS: Depth-First Search) に基づき1次元 ASCII 文字列へと展開する言語規格である。言語モデルの入力形式として最も広く普及しているが、その背後にある構文論的制約を正確に理解することが不可欠である。

#### 【SMILES の 5 大基礎構文規則】
1. **原子記号 (Atoms):**
   有機化学で標準的な原子（`B, C, N, O, P, S, F, Cl, Br, I`）は角括弧を省略して記述でき、自動的に水素原子による標準原子価が補完される（例: `C` はメタン $\text{CH}_4$、`N` はアンモニア $\text{NH}_3$）。形式電荷や異常原子価、同位体を含む場合は角括弧で明示する（例: `[NH4+]`, `[13C]`, `[Fe2+]`）。
2. **芳香族性 (Aromaticity):**
   ヒュッケル則を満たす芳香環内の原子は小文字で表現される（例: ベンゼンは `c1ccccc1`、ピリジンは `c1ncccc1`）。
3. **結合記号 (Bonds):**
   単結合 `-`（通常省略可能）、二重結合 `=`、三重結合 `#`、芳香族結合 `:`（通常省略）。
4. **環開閉記号 (Ring Closures):**
   環上の切断された結合ペアを同じ数値ラベルで示す（例: シクロヘキサンは `C1CCCCC1`、2桁以上の数値ラベルは `%10` 等と表記）。
5. **立体化学・幾何異性 (Stereochemistry - Isomeric SMILES):**
   不斉炭素の配置を四面体時計回り・反時計回り記号 `@`, `@@` で指示し、シス・トランス異性体二重結合を方向記号 `/`, `\` で指示する（例: `F/C=C/F` はトランス-1,2-ジフルオロエチレン）。

```
【アスピリン (Aspirin) の SMILES 導出と構造仕様】
文字列: CC(=O)Oc1ccccc1C(=O)O
解説:   [メチルカルボニル CC(=O)] - [エーテル酸素 O] - [芳香環ベンゼン c1ccccc1] - [カルボン酸 C(=O)O]
```

#### 【正準 SMILES (Canonical SMILES) アルゴリズムの非一意性課題】
同一分子であっても DFS 探索の起点原子およびトラバーサル順序によって多数の有効な SMILES が生成され得る（例: エタノールは `CCO`, `OCC`, `C(O)C` など）。データベースの正規化やモデル出力比較のため、**Morgan アルゴリズム**等に基づく「正準化 (Canonicalization)」が行われるが、RDKit と OpenBabel では内部不変量ラベリング規則が異なるため、**処理ライブラリが異なると正準 SMILES の文字列も合致しない**問題がある。

### 1.1.2 SMILES 列挙 (Randomized SMILES Enumeration) によるデータ拡張と正則化メカニズム

SMILES の非一意性は初期の課題と見なされていたが、Bjerrum (2017) および Arús-Pous et al. (2019) により、あえて正準化を行わず同一分子に対して多数のランダムな有効 SMILES 表記を生成してモデルに入力する **SMILES 列挙 (Randomized SMILES Enumeration)** が極めて強力なデータ拡張および過学習防止手法であることが実証された。

- **化学不変性の直接学習:**
  同一化合物に対して複数の異なる表記 (`CCO`, `OCC`) を与えることで、モデルは特定の文字配列パターンへの過適合から解放され、「文字探索順序に依存しない分子内部グラフのトポロジー不変性」を潜在空間で自動獲得する。
- **物性予測精度およびロバスト性の劇的向上:**
  ベンチマーク評価において、単一の Canonical SMILES で訓練した場合と比較して、10〜50倍の Randomized SMILES で訓練・検証時テスト時拡張 (Test-Time Augmentation) を行った場合、毒性分類・物性回帰タスクのテスト誤差が 15〜30% 削減されることが報告されている。

### 1.1.3 構文論的欠陥の克服モデル：DeepSMILES, SELFIES (100%妥当性保証), SAFE フラグメント表現

SMILES を直接デコード生成するタスクにおいて「括弧や環ラベルの閉じ忘れによる構文無効分子の生成」を解消するため、以下の進化的文字列表現が開発された。

#### 1. DeepSMILES (O'Boyle & Dalke, 2018)
括弧ラベルや環番号のペア一致をスタック操作に置換した改良表現。例えば、分岐閉じ括弧を個別の右括弧スタック記号 `)))))` で表現し、環閉鎖を分岐点からの単一スタックオフセット数値に置き換えることで、ペア不一致による無効化を防止する。

#### 2. SELFIES (Self-referencing Embedded Strings, Krenn et al., 2020)
チョムスキー文法階層（Type-2/Type-3 状態遷移モデル）に基づいて設計された、**100% 化学的妥当性を保証する分子表現**。

- **厳密な導出メカニズム:**
  SELFIES の全トークンは、現在の原子の空き原子価数状態に応じた「決定論的導出ルール」にマッピングされる。もしデコーダが原子価の上限を超える結合命令を出力したとしても、解釈系によって結合次数が自動的に飽和状態へ切り下げられるため、**生成される文字列は数理的に必ず存在する有効化合物となる**。
- **下流予測および生成タスクでの評価:**
  構文エラー率がゼロとなるため、自己学習言語モデルや VAE/GAN などにおいて、潜在空間の連続性と探索効率が劇的に向上する。

#### 3. SAFE (Sequential Attachment-based Fragment Embedding, Noutahi et al., 2024)
分子を原子単位で細切れにせず、機能的な化学ブロック（フラグメント・母核）の配列として表現する最先端の文字列表法。各ブロックは接続点番号付きの独立した化学構造単位であり、機能性置換基や創薬ファーマコフォアを直接的な語彙として学習できる。

### 1.1.4 化学言語モデルにおけるトークナイズ戦略の包括比較表と理論分析

言語モデルの性能は、文字列を入力ベクトル系列へ分割する **トークナイザー (Tokenizer)** の設計に直接依存する。以下は化学領域で利用される主要な5つのトークナイズ手法の定量的・定性的分析表である。

| トークナイズ手法 | 代表的な採用モデル | 平均系列長 (相対長) | 語彙数 (Vocabulary Size) | 化学的セマンティクス保持力 | 主な利点と課題 |
|:---|:---|:---:|:---:|:---|:---|
| **文字単位 (Character-Level)** | 初期の LSTM / Char-RNN | 長い (1.0x baseline) | 極小 (約 50〜80) | 低い (単一文字では結合や官能基の意味を持たない) | 未知語 (OOV: Out-Of-Vocabulary) がゼロ。系列長が長くなり遠隔依存性の学習難度が上がる。 |
| **原子・正規表現単位 (Regex Atom-Level)** | **SMILES-BERT**, Schwaller et al. | やや短い (0.8x) | 小 (約 300〜500) | 中程度 (`Cl`, `Br`, `[NH3+]` 等を単一トークン化) | 化学的に不可分な多文字原子やブラケット原子を保護。最も汎用的な標準仕様。 |
| **バイトペア符号化 (BPE / WordPiece)** | **ChemBERTa**, **ChemBERTa-2** | 短い (0.4x 〜 0.6x) | 大 (数百 〜 数千) | 高い (`c1ccccc1` 等の頻出環構造を1トークン化) | 系列長が圧縮されコンテキストウィンドウ効率が劇的向上。稀に化学的意味を持たない分割が生じる。 |
| **SMILES Pair Encoding (SPE)** | **SmilesPE** (Li & Fourches, 2021) | 最適化 (0.5x) | 約 3,000 | **極めて高い** (化学結合関係を壊さないペア結合) | 化学的に妥当なサブストラクチャのみを語彙化する化学配慮型アルゴリズム。 |
| **フラグメント・母核単位 (Motif / SAFE)** | **SAFE**, Group-SELFIES | 極めて短い (0.2x) | 非常に大 (数万) | **完全** (創薬上の母核・官能基そのもの) | 創薬研究者の直感と直接合致。大規模モデルや特化型生成設計において絶大な威力を発揮。 |

### 1.1.5 InChI / InChIKey の階層別構文仕様と SHA-256 ハッシュアルゴリズム

IUPAC（国際純粋・応用化学連合）と NIST により策定された **InChI (International Chemical Identifier)** は、SMILES の非一意性問題を数理的に解決した階層的正規化識別子である。

#### 【InChI の 6 大階層構造仕様】
InChI 文字列はスラッシュ `/` で区切られた階層（Layer）から構成される：
1. **主層・化学式層 (Formula Layer):** 原子の組成式（例: `/C9H8O4`）。
2. **骨格結合層 (Connectivity Layer `c`):** 重原子間の結合関係とトポロジー（例: `/c1-6(10)13-8...`）。
3. **水素原子結合層 (Hydrogen Layer `h`):** 水素原子の結合位置と移動可能プロトンの定義（例: `/h2-5H,1H3...`）。
4. **電荷・プロトン化層 (Charge Layer `q/p`):** イオン価数およびプロトン着脱状態。
5. **立体化学層 (Stereochemical Layer `t/m/s`):** 二重結合の幾何異性・四面体不斉中心の絶対立体配置。
6. **同位体層 (Isotopic Layer `i`):** 同位体標識原子の情報。

#### 【InChIKey (27文字固定長ハッシュ) の生成メカニズム】
可読な InChI をデータベース検索や機械学習キーに適合させるため、SHA-256 アルゴリズムを用いた固定長文字列 **InChIKey** に変換される。
- **フォーマット:** `XXXXXXXXXXXXXX-YYYYYYYYFV-P` (計27文字ハイフン区切り)
- **第1ブロック (14文字):** 骨格結合層 (`c` および化学式層) の SHA-256 ハッシュ。完全な骨格同一性を判定。
- **第2ブロック (10文字):** 立体化学層・水素層・同位体層のハッシュ (8文字) ＋ InChI バージョンタグ (1文字) ＋ 標準/非標準フラグ (`S`/`N`)。
- **第3ブロック (1文字):** プロトン化状態 (`N` は中性、`M` 等は荷電状態)。

このように InChI / InChIKey は**構造の重複判定および同定に極めて強力**である一方、文字列が過度に硬直・記号化されているため、自己注意機構 (Self-Attention) によって部分構造の類似性や官能基文脈を学習させるには SMILES や SELFIES、SAFE が適している。

### 1.2 分子表現学習における事前学習パラダイムの変遷

化学言語モデルにおける事前学習戦略は、NLPの発展と同調して以下の3世代の進化を遂げた：

1. **自己回帰型言語モデル (CLM: Autoregressive LM / SMILES RNN)**
   - 分子文字列 $S = (t_1, t_2, \dots, t_N)$ に対して、条件付き確率分布 $P(S) = \prod_{i=1}^N P(t_i | t_1, \dots, t_{i-1})$ を最大化。
   - 主に *de novo* 分子生成タスクで成功したが、下流の物性分類・予測においては双方向文脈を捉えにくいという限界があった。
2. **マスク化言語モデリング (MLM: Masked Language Modeling)**
   - BERT / RoBERTa を模範とした双方向表現学習。入力 SMILES/SELFIES トークンの約15%を `[MASK]` に置換し、周囲の化学文脈から元トークンを再構成。
   - 分子の官能基文脈や部分構造相関を獲得し、初期の **SMILES-BERT** や **ChemBERTa** の中核となった。
3. **多重タスク回帰 (MTR) および物理化学記述子誘導学習**
   - **ChemBERTa-2** において提唱された手法。単なる語彙の推測 (MLM) だけでなく、RDKit 等で計算される200種類以上の物理化学的記述子 (LogP, TPSA, 結合数, 分子量等) を教師信号とする**多重タスク回帰 (MTR: Multi-Task Regression)** を並行学習させることで、潜在空間に定量的構造物性相関が強制的に埋め込まれ、下流タスク精度が顕著に向上した。

### 1.3 主要化学言語モデル・基盤モデルの徹底解剖（アーキテクチャ・データ仕様比較）

### 1.4 多重タスク回帰 (MTR) 事前学習における物理化学記述子の徹底解説 (RDKit 200種記述子との共学習メカニズム)

ChemBERTa-2 (Ahmad et al., 2021) によって実証された最も画期的な知見の一つが、**マスク化言語モデリング (MLM)** 単独よりも **多重タスク回帰 (MTR: Multi-Task Regression)** を用いた事前学習の方が、毒性予測や薬効予測などの下流タスクで格段に高い予測表現を獲得できるという事実である。

#### 【MTR 事前学習の数理的メカニズム】
MLM は文字列中の隠された記号を予測する「局所的な語彙復元」タスクであるため、必ずしも分子全体の巨視的な物理化学的特性を表現空間に反映する保証がない。これに対し MTR は、入力 SMILES の潜在表現ベクトル $h_{\text{CLS}}$ に対し、RDKit 等で高速計算可能な200種類以上の物理化学記述子 $y \in \mathbb{R}^K$ ($K=200$) を同時に回帰予測させる損失関数を課す：

$$\mathcal{L}_{\text{MTR}} = \frac{1}{K} \sum_{k=1}^K \left( y_k - \hat{y}_k(h_{\text{CLS}}) \right)^2$$

これにより、Transformer アーキテクチャの潜在空間は「構造文法」だけでなく、「化学分子が現実の物理空間・生体内で示す物性相関」に基づいた幾何学的構造へと再配置される。

#### 【MTR で共学習される代表的物理化学記述子一覧】
| 記述子カテゴリ | 代表的パラメータ・関数名 | 化学・薬理学的意義と毒性・ADMET予測への関連性 |
|:---|:---|:---|
| **親水性・疎水性** | `cLogP`, `MolLogP` | オクタノール/水分配係数。脂溶性を反映し、血液脳関門透過性 (BBBP) や生体膜吸収の決定要因。 |
| **極性表面積** | `TPSA` (Topological Polar Surface Area) | 分子内の極性原子 (N, O など) の表面積総和。リピンスキーの法則 (TPSA $\le 140 \, \text{\AA}^2$) と密接。 |
| **トポロジー複雑度** | `BertzCT`, `BalabanJ` | 分子の分岐度・環構造の複雑性を表す情報論的指標。合成難度や立体障害を反映。 |
| **水素結合受容・供与** | `NumHDonors`, `NumHAcceptors` | 水素結合ドナー数・アクセプター数。薬物-受容体間ポケット結合や細胞毒性活性の必須変数。 |
| **分子柔軟性・回転結合** | `NumRotatableBonds` | 自由回転可能な結合数。配座エントロピーを決定し、タンパク質結合親和性に強く影響。 |
| **創薬適格性指標** | `QED` (Quantitative Estimate of Druggability) | 既知承認医薬品群の物性分布との類似度を表す0〜1の総合薬効スコア。 |

このように、MTR 事前学習は「ドメイン知識（ケモインフォマティクス記述子）と深層表現学習の最高峰の架け橋」であり、現代の化学言語モデルの設計において標準的な事前学習戦略となっている。

## 2. 毒性 (Toxicity) および薬効 (Efficacy / ADMET) 予測への適用とベンチマーク評価

### 2.1 毒性および薬効予測データセットの特徴と難度
化学言語モデルの評価には、**MoleculeNet** ベンチマークで標準化された以下のエンドポイントが用いられる。特に毒性・薬効データは以下の性質を持つ：

1. **強いクラス不均衡 (Class Imbalance):**
   スクリーニングアッセイ (HIV や Tox21 など) では、無毒・非活性化合物が 90% 以上を占める場合が多く、単なる正答率 (Accuracy) ではなく **ROC-AUC (Receiver Operating Characteristic - Area Under Curve)** や **PR-AUC** が指標とされる。
2. **多目的・マルチラベル予測:**
   Tox21 (12経路) や ToxCast (617アッセイ) は、単一分子が複数の生体標的に与える影響を同時に予測するタスクであり、中間層が獲得する表現の汎化性が直接試される。

#### 【定量比較からの重要な技術的洞察】
- **スケーリング則の成立:**
  事前学習分子数を 10M (ChemBERTa) $\rightarrow$ 77M (ChemBERTa-2) $\rightarrow$ 1.1B (MoLFormer) と拡大することで、全タスクにおいて一貫したスコア向上が確認できる。
- **多重タスク回帰 (MTR) の貢献:**
  ChemBERTa-2 では、MLM のみに依存したモデルよりも、化学記述子回帰 (MTR) で学習したモデルの方が D-MPNN ベースラインに勝利する確率が高い。
- **GNN との相補的優位性:**
  分子グラフモデル (Chemprop / D-MPNN) は局所的な化学結合性を正確に捉える一方、大規模言語モデル (MoLFormer) は長距離依存性や膨大な外部コーパスの化学的文脈を獲得できるため、近年の統合アプローチでは両者の表現を連結・アンサンブルする手法が主流化している。

### 2.3 2D/3D 分子構造表現・GNNとのマルチモーダル統合アプローチ

1D文字列に基づく化学言語モデルと、2D/3D幾何情報を組み合わせる最新の**マルチモーダルアーキテクチャ**では以下の3つのアプローチが存在する：

1. **表現の早期/結合フュージョン (Late/Hybrid Fusion):**
   MoLFormer や ChemBERTa から抽出した Transformer クラス埋め込み ($h_{\text{LM}}$) と、Chemprop (D-MPNN) からのグラフ埋め込み ($h_{\text{GNN}}$) を結合 ($[h_{\text{LM}} \;||\; h_{\text{GNN}}]$) し、多層パーセプトロン (MLP) に入力して下流タスクを予測する手法。
2. **対照学習によるアラインメント (Molecular Contrastive Learning):**
   言語モデルによる SMILES 埋め込みと、等変グラフニューラルネットワーク (EGNN) による 3D コンフォーマー埋め込みの間で InfoNCE 損失を最小化し、1D 言語モデルに 3D 空間配置のセマンティクスを内在させる (例: **GraphMVP**, **Uni-Mol**)。
3. **回転位置埋め込み (RoPE) と空間的アテンション:**
   MoLFormer が実証したように、SMILES 空間における原子間距離と現実の 3D ユークリッド距離は統計的に強い相関を持つ。RoPE を採用することで、陽に 3D 座標を入力せずともアテンションヘッドが「空間的な原子間接触」を学習できる。

## 3. 化学言語モデル特有の課題と先進的解決アプローチ

```
+-------------------------------------------------------------------------------+
|                       化学言語モデル特有の3大課題解決アプローチ                        |
+-------------------------------------------------------------------------------+
| 1. 構文妥当性 (Syntax Validity)                                                |
|    - 課題: SMILES生成・予測時の括弧・環記号破綻による「無効分子」の発生            |
|    - 解決策: SELFIES 文法論による 100% 妥当性保証 & 制約付きデコーディング         |
+-------------------------------------------------------------------------------+
| 2. データ漏洩・活性クリフ (Activity Cliff & Scaffold Split)                    |
|    - 課題: 類似分子間で活性が劇変する現象。ランダム分割による性能の過大評価         |
|    - 解決策: 厳密な Bemis-Murcko スキャフォールド分割 & コントラスト損失最適化      |
+-------------------------------------------------------------------------------+
| 3. 解釈可能性と薬理作用機構の説明 (Interpretability & SAR/Pharmacophore)      |
|    - 課題: ブラックボックス化しやすいニューラル予測根拠の解明                    |
|    - 解決策: アテンションマップ解析によるファーマコフォア・毒性原因部位のハイライト  |
+-------------------------------------------------------------------------------+
```

### 3.1 構文妥当性 (Syntax Validity) と SELFIES による構造保証
SMILES 表現に基づく生成モデルや翻訳モデル (MolT5 等) では、デコーダが出力する文字列の構文が破綻し、化学的に存在不可能な構造が生成される問題がある。

- **SELFIES (SELF-referencing Embedded Strings) の導入:**
  SELFIESは、すべての記号が強固な導出関数にマッピングされるチョムスキー言語ルールに基づく。いかなるトークン列も化学的原子価規則（Valence Rules）を満たす分子へ決定論的に変換されるため、構文エラー率を完全に **0%** へ抑え込むことができる。

---

### 3.2 活性クリフ (Activity Cliff) およびスキャフォールド分割 (Scaffold Split) への対応
創薬において、分子構造のわずかな修飾（メチル基一つやハロゲンの置換）によって生理活性や毒性が数十〜数百倍変動する現象を **活性クリフ (Activity Cliff)** と呼ぶ。

- **評価論理の厳格化 (Bemis-Murcko Scaffold Split):**
  ランダム分割によるベンチマーク評価は、学習データに存在する母核構造と同一の分子をテストセットに混入させるため、データ漏洩 (Data Leakage) や過大評価につながる。化学言語モデルの実用評価においては、必ず分子骨格単位でデータセットを分割する **Scaffold Split** または **Target/Time-split** が必須となる。
- **クリフ感度アテンション学習:**
  活性クリフを正確に検知するため、微小な部分構造差異に強い勾配ペナルティを課すトリプレット損失やメトリック学習が組み合わせられる。

---

### 3.3 解釈可能性 (Interpretability): アテンションマップによる薬理団 (Pharmacophore) の可視化
創薬研究者がモデルの判断を信頼するためには、「分子のどの部分構造が毒性あるいは薬効に決定的な影響を与えたか」を可視化・説明できることが不可欠である。

#### 【アテンション重みによる構造毒性相関 (SAR) の抽出手順】
1. モデルのラストアテンション層におけるクラストークン `[CLS]` から各 SMILES トークン $t_i$ へのアテンション重み $\alpha_{CLS, i}$ を集計する。
2. サブストラクチャや原子単位でのスコアへ投影し、RDKit 等の描画エンジンを用いて2D構造上にヒートマップとしてオーバーレイ描画する。
3. 例えば、**Tox21** モデルにおける変異原性 (Ames試薬毒性) の予測では、アテンションが芳香族アミンやニトロ基などの**既知の毒性アラート構造 (Structural Alerts)** に自動的に集中することが確認されている。

## 4. 総合考察と今後の展望 (2026年現在の現在地)

化学言語モデルは、初期のSMILES文字列上のNLP適応研究から脱皮し、2026年時点においては以下の3つの方向へと急速に収束しつつある：

1. **大規模マルチモーダル化学基盤モデルへの進化:**
   1D文字列のみならず、質量分析スペクトル、2Dグラフ、3D座標、さらには「生理活性アッセイの自然言語レポート」を統一コンテキストとして扱える **ChemDFM** や **ChemLLM** が普及し、専門家との対話を通じて毒性リスク判定や合成経路探索を行う AI アシスタントへと進化している。
2. **State Space Models (Mamba) による長系列・高分子ポリマー予測:**
   SMILES文字数が数千を超える抗体薬物複合体 (ADC) やペプチド・高分子においては Transformer の $O(N^2)$ 計算コストが致命的となる。これを解決する **ChemMamba** アーキテクチャが次の標準的選択肢として台頭している。
3. **高精度毒性予測パイプラインの実用実装:**
   単一モデルへの過信を排し、**MoLFormer-XL** + **D-MPNN (Chemprop)** + **物理化学記述子** のコンセンサスアンサンブルを行う設計が、製薬産業における ADMET スクリーニングおよび臨床試験成功率予測の最高標準として確立されている。
